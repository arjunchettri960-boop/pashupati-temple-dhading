# पशुपति मन्दिर धादिङ — वेबसाइट प्याकेज

यो ZIP प्याकेजमा मन्दिरको पूरा वेबसाइट र सजिलै फोटो/अडियो/YouTube Live अपडेट गर्ने संरचना तयार पारिएको छ।

## फोल्डर संरचना
- `index.html` — मुख्य वेबसाइट फाइल
- `images/` — मन्दिरका फोटोहरू राख्ने फोल्डर
- `audio/` — भजन तथा आरतीका MP3 फाइल राख्ने फोल्डर
- `README.md` — प्रयोग निर्देशिका

## १. फोटो ग्यालरीमा फोटो थप्ने सबैभन्दा सजिलो तरिका (HTML नचलाईकन)
GitHub मा `images` फोल्डर खोल्नुहोस् र आफ्नो फोटोलाई तलका नाम दिएर upload गर्नुहोस्:
- `temple.jpg` — मुख्य मन्दिरको फोटो (Hero र ग्यालरीको पहिलो ठूलो फोटो)
- `gallery-1.jpg` (वा `.jpeg`, `.png`, `.webp`)
- `gallery-2.jpg`
- `gallery-3.jpg`
- `gallery-4.jpg`
- ...यसैगरी `gallery-12.jpg` सम्म

वेबसाइटले `images` फोल्डरमा अपलोड भएका `gallery-1` देखि `gallery-12` सम्मका फोटोहरू **आफैं पत्ता लगाएर ग्यालरीमा देखाउँछ** र नभएको नम्बर स्वतः लुकाउँछ।

## २. कार्यक्रम हुँदा YouTube Live चलाउने तरिका
1. `index.html` खोलेर तलतिर रहेको `const YOUTUBE_LIVE_INPUT = "";` खोज्नुहोस्।
2. खाली `""` भित्र आफ्नो YouTube Live लिंक वा Video ID राख्नुहोस् (उदाहरण: `const YOUTUBE_LIVE_INPUT = "https://youtu.be/VIDEO_ID";`)।
3. Commit changes गर्नुहोस् — वेबसाइटमा स्वतः 🔴 LIVE भिडियो चल्नेछ।
4. कार्यक्रम सकिएपछि फेरि `""` खाली राख्नुहोस्।

## ३. भजन तथा आरती अडियो थप्ने तरिका
`audio` फोल्डरभित्र यी MP3 फाइलहरू upload गर्नुहोस्:
- `pashupati-bhajan.mp3`
- `shiva-aarti.mp3`
