# पशुपति मन्दिर धादिङ — GitHub Pages वेबसाइट

## प्रकाशित गर्ने तरिका
1. GitHub मा login गर्नुहोस्।
2. **New repository** थिचेर `pashupati-temple-dhading` नाम राख्नुहोस्।
3. Repository लाई **Public** छान्नुहोस् र Create repository गर्नुहोस्।
4. यो ZIP extract गरेर भित्रको `index.html` र `README.md` GitHub repository मा upload गर्नुहोस्।
5. **Commit changes** थिच्नुहोस्।
6. Repository को **Settings → Pages** खोल्नुहोस्।
7. **Deploy from a branch** छान्नुहोस्, Branch `main` र Folder `/ (root)` राखेर Save गर्नुहोस्।
8. केही मिनेटपछि `https://YOUR-USERNAME.github.io/pashupati-temple-dhading/` मा वेबसाइट खुल्छ।

## प्रकाशित गर्नुअघि बदल्नुपर्ने कुरा
- अहिले ग्यालरी र मुख्य ब्यानरमा नमुना Unsplash तस्बिर छन्। मन्दिरका वास्तविक तस्बिर राख्नुहोस्।
- आधिकारिक इमेल र Google Maps को सही स्थान लिंक थप्नुहोस्।
- पूजा समय, कार्यक्रम मिति र अन्य तथ्य व्यवस्थापन समितिबाट पुष्टि गरेर मात्र प्रकाशित गर्नुहोस्।
- यो static website हो; सूचना सम्पादन गर्न `index.html` फाइलमा लेखाइ परिवर्तन गरेर फेरि GitHub मा upload/commit गर्नुहोस्।

## तस्बिर बदल्ने तरिका
आफ्ना तस्बिर repository मा `images` नामको folder बनाएर राख्नुहोस् र `index.html` मा भएका `https://images.unsplash.com/...` URL लाई `images/your-photo.jpg` ले बदल्नुहोस्।
