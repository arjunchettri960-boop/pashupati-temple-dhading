# पशुपति मन्दिर धादिङ — अपडेट गरिएको वेबसाइट

यस संस्करणमा तपाईंले पठाउनुभएको मन्दिरको फोटो मुख्य ब्यानर, परिचय र ग्यालरीको पहिलो तस्बिरमा राखिएको छ।

## GitHub मा अपडेट गर्ने तरिका
1. ZIP फाइल Extract All गर्नुहोस्।
2. GitHub repository `pashupati-temple-dhading` खोल्नुहोस्।
3. **Add file → Upload files** क्लिक गर्नुहोस्।
4. Extract भएको `index.html` फाइल र `images` फोल्डरलाई upload क्षेत्रमा तान्नुहोस्।
   - `images` फोल्डरभित्र `temple.jpg` हुनुपर्छ।
   - GitHub मा संरचना यस्तो देखिनुपर्छ: `index.html` र `images/temple.jpg`
5. **Commit changes** थिच्नुहोस्।
6. केही मिनेटपछि GitHub Pages साइट refresh गर्नुहोस्।

यसले पुरानो `index.html` लाई नयाँसँग बदल्छ र `images/temple.jpg` थप्छ।
